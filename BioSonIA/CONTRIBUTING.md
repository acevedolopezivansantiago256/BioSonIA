# Contribuir a BioSonIA

## Flujo de trabajo
- Crea una rama `feature/<nombre>` desde `develop`.
- Haz commits claros (`feat`, `fix`, `docs`, `chore`, `refactor`).
- Abre PR a `develop` y solicita revisión.
- Tras pruebas en `stage`, merge a `main`.

## Estilo
- TypeScript con `strict` donde aplique.
- Python con tipado cuando sea posible.
- Comentarios claros para explicar decisiones.
